# KUHNI UI Kit

## Основа

- Фон страницы: `#ffffff`.
- Внутренние спокойные поверхности: `#f7f8f7`.
- Текст: графитовый `#171b1f`, вторичный `#6d747b`.
- Линии: тонкие нейтральные `#e1e6e4`, усиленные `#d2dad7`.
- Основной акцент: графитовые CTA без ярких синих и желтых заливок.

## Геометрия

- Малый радиус: `8px`.
- Контролы и компактные карточки: `12px`.
- Фото и крупные блоки: `8px`, если секция не требует большего радиуса.

## Контролы

- Базовая высота кнопок и контактных действий: `50px`.
- Фон обычного контрола: `#f7f8f7`.
- Primary action: графитовая заливка `#182026`, белый текст, без синих акцентов.
- Secondary action: нейтральная светлая поверхность, тонкая линия, графитовый текст.
- Hover: белая поверхность, более заметная линия, легкая широкая тень.
- Active: возврат к исходной позиции без скачков.
- Шрифт в контролах: `15px`, вес около `720`.

## Навигация

- Header и footer используют один набор пунктов: `Кухни`, `Материалы`, `Расчет`, `Этапы`, `Отзывы`, `Контакты`.
- Desktop header всегда sticky.
- Mobile header скрывается при скролле вниз и возвращается при скролле вверх; при открытом меню или модалке остается видимым.

## Отзывы

- Desktop: горизонтальная лента с 3 видимыми карточками.
- Tablet: 2 видимые карточки.
- Mobile: 1 карточка на экран.
- Фото в карточке должно быть достаточно крупным, чтобы отзыв не выглядел как мелкий текстовый блок.

## FAQ

- FAQ оформляется одной компактной светлой плашкой без отдельной правой панели.
- Desktop/tablet FAQ: две колонки вопросов; mobile FAQ: одна колонка.
- Используется классический accordion: активен только один вопрос, первый открыт по умолчанию.
- Между заголовком FAQ и списком держать заметный воздух `26-30px`; строки вопросов компактные, одинаковые по высоте, с ровным нижним разделителем.
- Не использовать крупные номера в FAQ-вопросах.

## Этапы

- На desktop этапы показываются одной строкой без пагинации.
- На tablet/mobile этапы становятся горизонтальной scroll-snap лентой с центрированными dots под карточками.

## Quiz

- Горизонтальный скролл вариантов живет только внутри image-options ленты, не на странице.
- В начале ленты видна только правая подсказка скролла; левая появляется только после фактической прокрутки вправо.
- Тексты вопроса и подсказки всегда переносятся внутри quiz-card и не выходят за границы формы.

## Mobile

- Не использовать горизонтальный overflow страницы.
- Trust/benefit элементы должны иметь одинаковую высоту и единую внутреннюю сетку.
- В mobile hero элементы benefits всегда растягиваются на ширину контейнера; не использовать `align-self: end`.
- В mobile hero benefits используют сетку `2x2`, иконка и текст выровнены по одной вертикальной оси внутри карточки.
- Внутренние заголовки quiz на всех устройствах должны быть визуально меньше заголовка секции.
- Важные CTA на мобильных занимают всю ширину контейнера.
- Не дублировать подписи и логотипы: если wordmark уже содержит текст, рядом не добавлять тот же текст.
